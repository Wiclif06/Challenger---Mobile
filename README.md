# AlwaysPet Mobile

Aplicativo mobile desenvolvido em React Native com Expo para a entrega de Mobile Application Development.

## Integrante

Felipe Wiclif Leal da Silva — RM 563901  
Grupo: AlwaysPet

## Requisitos atendidos

- Navegação entre telas
- Mínimo de cinco telas
- Protótipo visual funcional
- Formulário com manipulação de estado
- Armazenamento local com AsyncStorage
- Persistência de dados após reiniciar o app
- Demonstração em dispositivo físico ou emulador

## Telas implementadas

1. Login
2. Dashboard
3. Meus Pets
4. Detalhes do Pet
5. Cadastro de Pet
6. Alertas
7. Perfil

## Como executar

Instale as dependências:

```bash
npm install --legacy-peer-deps
```

Rode o projeto:

```bash
npx expo start -c --tunnel
```
